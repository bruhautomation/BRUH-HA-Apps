What turning Protection mode off does
  • It lets this one add-on see every process on the machine and its command line: Home Assistant, the Supervisor, every app and the operating system. Command lines occasionally contain a password someone typed into a setting.
  • It lets this add-on send signals to processes in other apps, which is how End process works. Ending the wrong thing can stop an app; ending part of the operating system can make the machine unreachable until it is switched off and on again. That is why End process is a separate switch, off by default, and is never offered for Home Assistant, the Supervisor or the operating system.
  • It does not let it read other apps' passwords or tokens. Its security profile blocks reading another process's environment and memory, whatever Protection mode says.
  • It does not open any network port and changes nothing about your other apps.
  • The Supervisor shows this add-on's security rating as 5 instead of 6, because it asked for the process list at all.

When you are finished, switch Level 2 off here and turn Protection mode back on.

Runaway apps

An app using at least this share of the whole machine's CPU for this long is marked as running away, and the Home Assistant sensor turns on. Nothing is stopped automatically.
