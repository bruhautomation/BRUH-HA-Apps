What brAIn thinks is broken

Problems found while analysing your home — a dead battery, a sensor that stopped reporting, an automation that can never fire. Send brAIn to fix it, or tell it this isn't a problem here and it will never raise it again.

⚙ Settings

Both run the same Claude Code, with the same login, the same /config and the same permissions — the difference is how you see it. Chat reflows to the screen it's on, folds tool calls into one line each, and gives you a normal text box (so dictation and autocorrect behave); it's the one to use on a phone. Classic is a real terminal, which is what you want for anything that draws its own screen — a TUI, htop, an installer — or for running shell commands yourself. You can switch at any time from the Terminal tab.

Your Claude plan refills a usage window every 5 hours. Once the window's usage reaches this share, Insights pauses automatic runs so it never crowds out your own Claude use — they resume as the window rolls over. Manual clicks are never blocked.

💡 Token-saving tips: each card's ✎ dialog can set fixed daily run times (e.g. “07:00, 19:00”), a longer every-N-hours interval, or disable that card entirely — scheduled times use far fewer tokens than short intervals.
