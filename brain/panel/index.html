Let BRain get to know your home

Before it suggests anything, it studies your house — how it's named, when it's occupied, what it uses, how it behaves. Then it proposes cards that are actually about your home rather than a generic one.

This takes a few minutes and runs in the background — you can close this tab and come back.

It'll read what it learned and propose a handful of cards.

Pick the ones you want. You can add, edit or remove cards any time.

Generic cards about a home BRain hasn't been able to read would just be noise on every run, so it won't invent any. Add more entities or let history build up, then try again.

The analyst only sees the collected data snapshot — prompts can steer the analysis, not fetch new data.

⚙ Settings

Your Claude plan refills a usage window every 5 hours. Once the window's usage reaches this share, Insights pauses automatic runs so it never crowds out your own Claude use — they resume as the window rolls over. Manual clicks are never blocked.

Removed cards

Built-in cards you removed with ✕. Their definitions ship with the add-on, so they can come back any time — restoring one brings back an empty card you can generate again (its past runs and feedback are gone for good).

💡 Token-saving tips: each card's ✎ dialog can set fixed daily run times (e.g. “07:00, 19:00”), a longer every-N-hours interval, or disable that card entirely — scheduled times use far fewer tokens than short intervals.
