# BRUH Browser

brAIn's hands on the web: a real Google Chrome with Anthropic's Claude in
Chrome extension, in your Home Assistant sidebar, so brAIn can run errands
on websites for you — a grocery cart first.

- It does nothing on its own: it exists for **brAIn**, and refuses to start
  without it.
- It **never buys without your approval**: it builds the cart, brAIn reads it
  to you, and a purchase is a second errand you approve.
- Needs a **paid Claude plan** and two one-time sign-ins with the same Claude
  account. **amd64 only.** **Experimental.**
